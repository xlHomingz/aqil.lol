Windows-un tarixi

1985-ci ildən bu günə qədər

Windows-u Microsoft şirkəti yaradıb. Microsoft-u 1975-ci ildə Bill Gates və Paul Allen qurublar.

Windows-dan əvvəl kompüterlərdə MS-DOS var idi.Orada siçan yox idi, hər şeyi klaviatura ilə əmr yazaraq edirdilər.

İlk versiya Windows 1.0 idi və 1985-ci ildə çıxdı. Windows 3.0 isə 1990-cı ildə çıxdı və ilk dəfə çox satıldı.

Köhnə Windows

Windows 95 ilə ilk dəfə Start menyusu və tapşırıq paneli gəldi. Bu iki hissə bu gün də var.

Windows XP 2001-ci ildə çıxdı.Yaşıl təpə və mavi göy olan divar kağızı bəlkə də dünyanın ən çox görülən şəklidir.

Windows 7 2009-cu ildə çıxdı, sürətli və rahat olduğu üçün çox sevildi.

Yeni Windows

Windows 10 2015-ci ildə çıxdı. Onun dəstəyi 2025-ci ilin oktyabrında bitdi.

Ən son versiya Windows 11-dir və 2021-ci ildə çıxıb.Onda Start menyusu və tapşırıq paneli ekranın ortasındadır.
