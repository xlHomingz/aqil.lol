Dünyanın ən məşhur əməliyyat sistemi

Əməliyyat sistemi nədir?

Əməliyyat sistemi kompüterin əsas proqramıdır. Kompüter işə düşəndə ilk o açılır və bütün başqa proqramlar onun üzərində işləyir.

Ən tanınmış əməliyyat sistemləri Windows, macOS və Linux-dur.Telefonlarda isə Android və iOS istifadə olunur.

Niyə adı "Windows"dur?

Windows ingilis dilində "pəncərələr" deməkdir. Hər proqram ekranda ayrıca pəncərədə açılır, sistemin adı da buradan gəlir.

Masaüstü kompüterlərin təxminən 70%-i Windows ilə işləyir.

Windows-un əsas hissələri

Start menyusu - bütün proqramlar buradan açılır.

Tapşırıq paneli - ekranın aşağısındakı zolaq, açıq proqramlar burada görünür.

Fayl Bələdçisi - kompüterdəki qovluqlara və fayllara baxmaq üçündür.

Zibil qutusu - silinən fayllar əvvəlcə bura düşür, sonra tam silinir.
