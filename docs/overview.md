# Overview

## What this is

This is one real story. A person noticed that part of a company website showed personal data. He reported it in private and then watched what happened. It is written so that anyone can follow it.

## How I worked

- **Who:** Agil Mammadov, a computer science student, working alone.
- **What I looked at:** The Work & Travel website (workandtravel.com) and a chat helper on its English site.
- **What I did:** I opened public pages in a normal browser, read the answers, took screenshots and wrote to the company.
- **What I did not do (as far as my records show):** I did not use the data. I did not send forms with real values. I did not call write actions. I did not try to get around any login. When a page asked for a login or said "no", I stopped.
- **Permission:** I had none before I looked. See the [disclaimer](../README.md#disclaimer).
